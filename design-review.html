Design review · 2026-10-02

向 Bear Neo 收敛：
让纸和线赢，别让卡片和玻璃赢

一份基于 getdesign.md 参考库、对比 hugo-bearneo 极简血统与 hulatu.com 现有实现的改造建议。目标不是变成 Bear Blog，而是把 Bear Blog 的克制，装进你自己的「纸账 + 印章」身份里。

画布 冷白纸 / 墨染夜色 强调色 印章红 ×1 阅读宽 680px 圆角 10–12px
01

一句话诊断

你的博客已经在做 Bear Blog 的内容，但还没完全用 Bear Blog 的容器。

你保留了极简的血统——窄栏、衬线、深色模式、快。但视觉实现一度漂向了「Apple App」：白卡片 + 投影 + 22px 大圆角 + 页头毛玻璃。而你自己给出的比喻「纸账 + 印章」本来就指向 Bear Blog 的克制——一本账本没有投影，只有横线和墨。所以方向不是"再设计一套"，而是让纸的比喻赢回来。

02

你现在站在哪

把「容器语言的重量」当作一根轴：左端是 Bear Blog 的裸纸，右端是移动 App 的卡片玻璃。你的内容与声音在左端，但容器与装饰偏在右端。

Bear Blog
纸 + 字，零容器
← 目标
纸 + 线 + 印章
你现在
卡片 + 玻璃
裸纸卡片玻璃

结论：要移动的只有「容器」这一端，内容、字体、功能全部原地保留。这是一次减法，不是重做。

03

getdesign.md 里，谁和你对得上

从 npx getdesign@latest list 列出的 80+ 个品牌里筛出四个气质相符的，作为「借纪律」的对象。它们不替代你的身份，只提供成熟的克制手法。

最贴 · 编辑血统

Wired

纸白画布、衬线标题 + 无衬线结构 + 等宽标签的三分工、用 1px 发丝线分行而非卡片、无投影。这正是「衬线标题 + 等宽元信息」的权威版本。

最贴 · 暖色 + 单一强调

Claude / Anthropic

暖色画布 + 一个暖强调色（珊瑚橙，气质接近你的印章红），且强调色用得极稀缺。它证明了"暖红 + 编辑式排版"是一套成立的组合。

借纪律 · 层级

Notion

hairline elevation——层级靠 1px 线和表面色深浅，不靠投影；一个结构性强调色，其余用装饰性"贴纸"。你的书影音卡片正好可以定位成"贴纸"。

借纪律 · 克制

Linear

表面阶梯代替投影，圆角统一 12px，强调色只出现在品牌标 / 焦点 / 主 CTA。是"圆角别放大、强调色别滥用"的最好参照。

04

最关键的一处：文章列表

首页列表是全站最常被看到的一屏。它现在是"一张带投影的白卡片"，改成"落在纸上的账目行"——这一个改动，方向就对了。

05

改造路线图

P0收益最大

把「卡片」退回「纸 + 线」

这是唯一一个"改了就对了"的动作，先做它。

  • .post-list 去掉 background/border/box-shadow，列表落到纸上，行间改发丝线
  • .post-row:hover 去掉底色块与 translateY，只保留标题变红
  • .group-card / .category-card / .media-card 撤掉 --shadow-sm，层级改线 + 纸背色
P1手感

圆角与阴影收敛

把"App 感"的两个来源同时收一档。

  • --radius-card 22→12 · --radius 16→12 · --radius-row 14→10
  • 全局清理阴影：只留给 .search-box / 灯箱 / 移动菜单 / .back-top
P1性能 + 观感

页头去玻璃

毛玻璃在常驻固定元素上每帧重算，是滚动掉帧的大头；在中文长文博客里收益很小。

  • 去掉或大幅降低 .site-header 的 backdrop-filter
  • 改「纸底 + 滚动时出现一条 1px 底线」（Wired 的 masthead 手法）
P2品牌电压

让印章红更稀缺

红是品牌电压，电压要省着用才亮。复核每一处 var(--accent)。

  • 保留：链接 / 悬停 / 激活 / 焦点环 / 一个「签名时刻」
  • 降级：纯装饰性的红（如阅读进度条、导航装饰线）可考虑降到 --ink-soft
P2锦上添花

借一点 bearneo 的能力

功能上你已经很全，只差这两样可选。

  • 首页可选做「年份分组」（归档页已有该能力）
  • 上赞（Kudos）可选——Bear Blog 的标志性互动
