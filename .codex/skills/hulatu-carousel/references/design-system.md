# HULATU Design System（抖音图文版）

胡拉图抖音图文的唯一视觉规范。任何一页都不得脱离本规范。落地实现见 `scripts/render.js` 顶部的 Design Tokens 与版式函数，两处必须保持一致。

## 画布

- 1080 × 1440 px（抖音 3:4）
- 导出 PNG，Chrome 截图时 `--force-device-scale-factor=1`

## 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#F7F6F2` | 页面底色 |
| `--ink` | `#171717` | 标题、正文主文字 |
| `--muted` | `#6B6B6B` | 辅助文字、页码、日期 |
| `--hairline` | `#D9D7D0` | 分割线、边框 |
| `--accent` | `#A34A32` | 砖红：品牌点、kicker、强调词 |

配比：米白底占页面 85% 以上，黑字为主，砖红 ≤ 5%。禁止大面积色块、渐变、阴影。

## 字体

- 正文：Hiragino Sans GB（macOS 系统字体；其他平台回退见 render.js）
- 标题/强调：STHeiti Medium（比正文更重，形成层级）
- 数字与英文沿用当前字体；渲染脚本按字符宽度做确定性折行
- 行高：标题 1.25–1.35；正文 1.7–1.8
- 字号阶梯：

| 层级 | 字号 | 字重 | 备注 |
| --- | --- | --- | --- |
| 封面标题 | 84px | 700 | 最多 2 行 |
| 正文页标题 | 64–72px | 700 | 最多 2 行 |
| 正文 | 38–42px | 400 | 30–80 字 |
| 条目 | 38px | 400 | list 版式 |
| kicker | 26px | 500 | 小号辅助文字 |
| 页码/脚注 | 26px | 400 | muted 色 |

## 栅格与留白

- 左右边距 100px，上下边距 110px；内容区宽度 ≤ 880px
- 页面结构固定为三段：顶部品牌栏 → 中部内容（垂直居中）→ 底部细线 + 页码
- 品牌栏：`·` 形砖红品牌点（10px 圆角）+ 「胡拉图说」+ 右侧 kicker
- 保持大量留白：内容与边框之间至少 60px 空白

## 版式（slide types）

1. **cover**：品牌栏 + 标签（如「开学季」）+ 封面大标题 + 一句副题 + 日期 · hulatu.com
2. **content**：kicker（如 `01 / 核心观点`）+ 大标题 + 正文，最多 1 段
3. **list**：kicker + 大标题 + 3–4 条短条目，每条约 20 字，砖红数字序号
4. **quote**：全页居中引用，左侧砖红竖线 + 大引号「」，下方小字署名
5. **cta**：关注「胡拉图说」+ 一句话定位（运动 · 健康 · 工具 · 生活）+ hulatu.com

## 细节规则

- 一页一个观点；标题 ≤ 18 字、两行以内
- 强调只用加粗或砖红词，不叠加效果
- 不加图片、emoji、渐变、阴影、圆角卡片（品牌点除外）
- 页码格式统一 `01 / 08`，封面与 CTA 也显示
- 中英文混排时数字与英文使用数字字体
- 文字不得溢出画布；正文超长时先精简文案，而不是缩字号
