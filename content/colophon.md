# 只写年月 —— 页头显示「最后更新」。
updated: "2026-10"
---

书的最后一页常常有一小段版权页，讲这本册子用的什么纸、什么字体、印了多少册。网站没有末页，但这一页想说的是同一件事：**这个站是怎么做出来的。**

写下来有两个原因。一是同行的博客常常会问，与其一条条回，不如摊开写；二是写给以后的自己 —— 过半年回头看，能想起来当初为什么这么拧。

## 骨架 {#gu-jia}

整站用 [Hugo](https://gohugo.io/) 生成，**没有用任何第三方主题**，`layouts/` 里的模板是一行一行写的。

不是为了炫技。这个站想要的不是「一套博客模板」，而是一个具体的样子：冷白的纸、发丝线、一枚印章红。主题能给我的是别人的一整套决定，而这里每一处我都想自己拧一遍。

- **构建** —— Hugo extended，站点锁定了版本，本地、GitHub Actions、Cloudflare Pages 三边同一个，免得出现「本地好好的、上线就崩」
- **托管** —— Cloudflare Pages，推 GitHub 自动发布
- **评论** —— [giscus](https://giscus.app)，评论内容存在 GitHub Discussions 里
- **统计** —— [GoatCounter](https://www.goatcounter.com/)，不写 Cookie、不认人
- **图片** —— 自有域名 `img.hulatu.com`，按显示尺寸走 Cloudflare 的图片变换

另外还有四个子站（`run.` / `shot.` / `share.` / `profile.`），同一套手写的 Hugo 放在 `sites/` 里各自独立构建。

## 字 {#zi}

**这个站不下载任何字体。** 全部走系统自带的三套栈，各守一职：

- **衬线**（Songti SC / 思源宋体…）—— 站点名、页标题、文章标题
- **无衬线**（PingFang SC / 系统 UI 字体）—— 正文、导航、按钮
- **等宽**（SF Mono / Menlo…）—— 日期、字数、期号这些以数字为主的元信息

第三条最容易被忽略，也最有用：日期走等宽之后，列表里每一行的日期天然对齐成一列，扫视的时候不会随数字的宽度左右抖。

不下载字体是有代价的 —— 换个系统，看到的字就不一样。但我更愿意付这个代价：一个几十 KB 的字体文件换来的「一致」，抵不上它拖慢的那一次首屏。

## 色 {#se}

全站只有一个强调色，我叫它**印章红**（`#c73e2f`）。

它只出现在五个地方：**可交互、当前状态、焦点、一个签名时刻、量**。除此之外一律用字重和留白解决 —— 红是要省着用的，用得越少，出现的时候越有分量。

底色是冷白的纸（`#f6f6f8`）；深色模式是墨染的夜色（`#0b0b10`），不是简单反色。

## 线与圆角 {#xian}

**层级靠线，不靠影。** 全站没有一处常驻的投影，分隔靠 1px 的发丝线；投影只留给真正浮在页面上的东西 —— 搜索面板、图片灯箱、手机菜单。

圆角收在 10–12px。22px 的大圆角读起来像 App，不像一本账。

正文宽度 680px、字号 17px、行高 1.8。这个宽度是照[少数派](https://sspai.com)的文章页量的 —— 再宽，一行就跑得太远，眼睛回行会累。

## 快 {#kuai}

**快是这套设计的一部分，不是工程指标。**

- 首屏要用的 CSS 直接内联进 HTML，按页型分成四个模块组合 —— 文章页不会背上归档页的样式
- 用浏览器原生的 Speculation Rules 预取：你点链接之前，下一页已经渲染好了
- 搜索是纯前端的，索引在构建期生成，不查服务器
- 不加载外部字体、不加载图标库、不挂任何第三方 JS 框架

## 你留下了什么 {#ni-liu-xia-le-shen-me}

本站不使用 Cookie，也不认人。留在你自己浏览器里的只有一样：搜索面板的最近几次搜索。只在本机，清空浏览器数据就没了 —— 细节写在[隐私政策](/privacy/)里。

键盘能走通全站：搜索是 `/` 或 `⌘K`，焦点环只在键盘操作时出现，系统开了「减弱动态效果」就把过渡和动画关掉。

## 血统 {#xue-tong}

这套东西不是从零想出来的，它有一条很清楚的来路：

- [Bear Blog](https://bearblog.dev) 和它的 Hugo 移植 [hugo-bearneo](https://github.com/rokcso/hugo-bearneo) —— 「纸 + 字」，几乎不用容器去框内容，快得不像是设计过的
- 正文宽度与阅读节奏的参照来自[少数派](https://sspai.com)的文章页
- 书影音卡片上那点 ±1.2° 的旋转，来自 Notion 的贴纸原则：**装饰永不承担结构**

## 刻意没做的事 {#ke-yi-mei-zuo-de-shi}

- 不给列表和卡片套白色容器 + 投影 + 大圆角
- 不在卡片里再套一层卡片
- 不在悬停时挂投影
- 不引入第二个强调色
- 不用毛玻璃做常驻页头
- 不在标题上加省略号 —— 标题是列表里唯一的信息，截它等于把列表变成一串「…」
- 不为了极简删掉功能。搜索、目录、灯箱、周刊、评论都是保留项；**要收敛的是装饰，不是能力**
