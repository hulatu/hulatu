## 提前声明 {#ti-qian-sheng-ming}

我目前使用的 Mac，是 2021 款 MacBook Pro 14 inch M1 Pro 芯片的版本，16 G 运行内存 + 1 TB 储存的版本。目前的系统版本是 macOS 15.8.1，除了有时候网络断链、重连后会发生一些网络问题外，其他使用体验都 OK。

我目前使用的软件，全都基于我这台设备以及版本号运行，基本没有问题、稳定运行。

顺带谈谈我个人对于所有电子产品「是否更新系统」的看法：早晚得更新。抛开设备、隐私和信息安全问题，就拿我们平日的使用体验来说，各种主流应用的更新迭代、旧 Bug 的修补以及新功能的迭代，都是基于不同平台不同设备的最新几代去适配的，换言之，如果我们一直守着旧的系统版本去使用，一段时间还好，但时间一长，多少会出现一些小 Bug，更有甚者，会遇到服务器停止提供服务的情况，就是旧版本对应的旧软件，压根就用不了、无法登录、闪退等等。

所以我的理解是：任何设备，如果更新到了一个稳定、流畅、电量消耗均衡的版本，可以留存时间久一些，因为它目前使用起来没有什么问题。但有新版本出现时，「不急着」尝鲜，让子弹飞一会儿，等到新版本更新到后面几版的时候，一切趋于稳定了，我们再更新到新版本，这样的话，就不用忍受大版本前期更新的小 Bug 频出的烦人时期。

好了，开始今天的 APP 分享之旅。

## 不喜欢，但不能卸载 {#bu-xi-huan-dan-bu-neng}

**WeChat** 🆓

微信，真的是一个很不讨喜的软件，因为它有太多可以做得更好的地方，都做得不够好。

- 不被监视
- 不那么臃肿
- 不那么封闭

这 3 个最基本的要求，是它、是一个文明社会的通讯软件本就能、就应该达到的要求。但是现实并不是这样，除了没有开屏广告这点好评外，微信距离往日的「小而美」越发遥远。貌似让很多人都已经忘了它最初的精致模样，那它又是怎么变成了如今的狼人模样呢？为了谁？因为谁？

但没办法，「加个好友」已经成为了简中世界里，交友的起手式，并且已经很多年了。或许「记一下我的电话」早已成为了过去式。

如今，每天与家人的交流、工作的交接联络等等，都离不开微信，所以我们也「不得不继续留着」微信。

但这并不能说明微信做得有多么好、有多么优秀，只是证明了在简中世界里，它的用户基础是如此庞大，「太多人在用」这才是它最根本的护城河。至于它的支付、小程序、覆盖我们生活的方方面面，这些都是可以忍痛割舍的，但是「别人都在用微信」，所以我也不得不用，这个我们几乎无法改变。

我也希望我们能有一款像 Signal 这样的通讯软件，成为国民级的应用。真正做到 1 个工具，干干净净只做好 1 件事。

软件官网：https://mac.weixin.qq.com/ 

Homebrew 安装方式：`brew install --cask wechat` 

App Store 下载链接：[WeChat for Mac](https://apps.apple.com/us/app/wechat/id836500024?mt=12)

**Office** 💰

因为不能像 Markdown 那样使用简单的「键盘操作」，就获得一个不错、有条理、有主次的排版体验，于是乎我极其讨厌使用 Word。因为「写」东西，很多时候本就是需要沉浸、投入、不被打断的过程。

就是你能想象嘛：一个为了码字、排版而生的软件，很多时候遇到的一些格式、设置问题，我居然要去「查资料」，看如何解决。甚至很多时候还找不到解决方案。

我不否认 Word 的专业和强大，但对我而言，实在太「重」、太复杂。

我很不喜欢用 PowerPoint，因为操作界面不清爽、选中元素的逻辑是我画出来的框，必须「完全包围」某个元素，它才能被选中，这个其实挺不符合操作本能的。

主要是用 Keynote 用习惯了，从使用习惯和操作逻辑上，我都觉得 Keynote 更适合「用来干活」的人。

PowerPoint 的工程师，感觉是「生怕你一下子就找到某个设置」在哪里而设计的，而且有时候为了调一个东西，需要点击多级菜单，很反人类。而 Keynote 很多东西，靠直观的图标等等就能知道它是用来干什么的，让人很容易找到。

Excel 可能是我最陌生的一个工具，我其实没用到过什么 Excel 的高级功能，很多基本的数据分析、清洗、处理等等，我都是用 Python 和它相关的库来完成；简单一些的记录，我会用 Mac 自带的 Numbers，我觉得美观、大气。

综上：我并不喜欢 Office 三件套。但是因为大家都在用，办公领域和文献格式排版等等具体细节的要求，也使得我离不开它们、我不能不用。还是那个现象——大家都在用、考虑到兼容性和通用性，我们即使有更好的选择，也很难按照自己的意愿去用想用的东西。

除此之外，Mac 上我留存的其他 APP，我都还挺喜欢的，因为可以根据我自己的喜好选择。

软件官网：[Microsoft 365 for Mac](https://www.microsoft.com/zh-cn/microsoft-365/mac/microsoft-365-for-mac) 

Homebrew 安装方式：`brew install --cask microsoft-office` 

App Store 下载链接：[Microsoft 365（包含 Word、Excel、PowerPoint 等）](https://apps.apple.com/us/app-bundle/microsoft-365/id1450038993?mt=12&platform=mac)

## 主力 APP {#zhu-li-app}

**Typora** 💰

这是我最喜欢的一款 Markdown 写作应用，可以随意更换 [主题](https://theme.typora.io/)，有超级好的「即时渲染」功能，可以连接图床用 uPic 上传博客图片，支持图片预览，没有多余的 AI、插件等等，干净、只保留最原始的书写体验。

满足这些的，我想不出来太多选择，并且它的设计很极简、很符合我的审美，所以没有理由拒绝。

![Typora](https://img.hulatu.com/post/mGDppQ.png)

软件官网：https://typora.io/ 

Homebrew 安装方式：`brew install --cask typora`  

**Apple 备忘录** 🆓

Apple 备忘录虽然对 Markdown 的支持不够友好，但这和我使用它不冲突。

我最喜欢的一个部分就是备忘录的「标签」管理，可以在一个新的页面里无论写什么，找个地方敲击 `Shift + 3`，打出一个 # 键，然后给自己写的东西归个类（比如 #日记），后面很容易找到，我很喜欢这个设计，找东西、整理东西很好用。

有时候一些不成体系的想法、碎片内容、简单日记，我就打开备忘录，然后一口气写出来，最后打上个标签，后面写长文、写周刊的时候要用到，很快就能找到。

因为我在备忘录里用来做的东西都是「偏短、偏及时性」的，所以无关乎它是否很好地支持 Markdown，加上 Apple 原生自带，没有理由不把它利用起来。

![备忘录标签](https://img.hulatu.com/post/4uzGCh.png)

软件官网/官方使用指南：https://support.apple.com/guide/notes/welcome/mac  

**uPic** 🆓

一款开源的 Mac 平台的图床软件，搭配 Typora 可以很方便地把图片展示在我的博客上。由于我的图床是基于 Cloudflare R2 搭建的，所以我的 Markdown 图片链接都是带有 `img.hulatu.com/xx` 的，也不会被公众号屏蔽，复制过去是可以直接使用的，不用再一张张添加图片。

软件官网/项目主页：https://github.com/gee1k/uPic  

**Pixelmator Pro** 💰

Mac 端的 PS，可以这么理解，但是远比 PS 易上手、轻量美观。我平时其实很少有修图的需求，但有时候科研画机理图、做 PPT、文章封面图等等，需要抠图、调整图片，这个应用很好用。

软件官网：https://www.pixelmator.com/pro/ 

App Store 下载链接：[Pixelmator Pro](https://apps.apple.com/us/app/pixelmator-pro/id1289583905?mt=12)

**Keynote** 🆓

Mac 端系统自带的 PPT 软件，我已经不止一次夸赞过它。它不但可以让我们在短时间内做出一份能用、美观的 PPT。更重要的是，这个过程中，它给到我的体验是无与伦比的，不会因为需要找什么功能、按钮和设计去「搜索指南」，从而打断我制作 PPT 的过程。

并且，大名鼎鼎的「神奇移动」效果，就是最早由 Keynote 推出的，让 PPT 的动画，高级了不知道多少个档次。

![Keynote 神奇移动效果](https://img.hulatu.com/post/ZiNZLY.gif)

它还可以用来做简单的动画、转场，做自媒体的人，真的很适合把玩一下 Keynote 这个软件，可能会精简自己的工作流，也可以帮自己省下一笔付费软件开支。

推荐资源：[江湖人称小 AE，用 Keynote 1 小时搞定平面动画](https://www.bilibili.com/video/BV11anUz7EBw/?vd_source=faa4a04597a50c1354e7975248079b6f)

软件官网：https://www.apple.com/keynote/ 

App Store 下载链接：[Keynote for Mac](https://apps.apple.com/us/app/keynote/id409183694?mt=12)

**预览**

平时看文献、做标记，我都是用 Mac 自带的预览软件打开 PDF 文件，我没觉得哪里不够用，而且也会显示目录、缩略图。

预览软件，用来看图片也是可以的，搭配上 Mac 的空格预览，我就很少用其他软件看图。

并且预览软件支持简单的修改图片、修改调整 PDF文件，我觉得这就很够了。

官方说明：https://support.apple.com/zh-cn/guide/preview/welcome/11.0/mac/15.0

**图书**

有时候我会在累了、不想写东西、不想看视频的时候，在 Mac 上打开图书软件看会儿书，体验还真挺好的——简洁、快速，只需要导入自己在 Z-Library 下载的 .EPUB 文件就可以畅读了。

我一般调整到屏幕的 1/3 宽度、全高，觉得这个宽幅用来看书正好，过宽过窄都没有更好的体验。

官方链接：https://www.apple.com/apple-books/

**NetNewsWire** 🆓

因为我个人写博客，平日也会关注一些博友、我喜欢的博客，所以一个 RSS 订阅器是必要的。这个开源的 NetNewsWire 就很适合用来订阅一些自己喜欢的信息源，我觉得很简洁、够用。

![RSS 订阅](https://img.hulatu.com/post/0oXGBS.png)

软件官网：https://netnewswire.com/ 

Homebrew 安装方式：`brew install --cask netnewswire`  

**Helium** 🆓

我每天用得最多的浏览器，相比于 Safari，它肉眼可见的性能更好、打开网页的速度更快。并且，它能安装各种 Chrome 网上应用店的扩展，可以获得更好的浏览器体验。而且，它还没有了 Google 的一些收集信息、遥测技术等等，很简洁。

所以我的主力浏览器是 Helium。

![干净的浏览器](https://img.hulatu.com/post/cXkI7W.png)

软件官网：https://helium.computer/ 

Homebrew 安装方式：`brew install --cask helium-browser`  

**Firefox** 🆓

因为 Firefox 在 Mac 上自带 Profile 的功能——能在浏览器中分区、数据分隔、互不影响。我有一个「Media」分区用来登录保留我的一些自媒体账号，方便发布内容。另一个分区是「World」，用来作为我浏览外网的庇护所。我一般就这些用处。

软件官网：https://www.firefox.com/ 

Homebrew 安装方式：`brew install --cask firefox`  

**Safari** 🆓

一个让我又爱又恨的浏览器，它能满足我日常绝大部分需求。原生的手势操控、与 Apple 生态的无缝衔接、简洁的标签栏紧凑模式……这些我基本在其他浏览器上没看到过。Orion 浏览器虽然有一些 Safari 的影子，但是还是不如 Safari 丝滑自然。

用到它主要是我外出的时候移动使用，且没有充电支持。开 Safari 的耗电速度确实比其他浏览器好很多。有时候我会打开 Safari 看一些文字内容，觉得体验比其他浏览器要好不少，我不知道是不是心理安慰，但是用双指放大、缩小等等的调节，很灵敏跟手，好用！

![Safari 使用](https://img.hulatu.com/post/zaRVJi.png)

软件官网/官方使用指南：https://support.apple.com/guide/safari/welcome/mac  

推荐资源：[如何配置一个好用的浏览器](https://hulatu.com/posts/2026/09/28/set-browser/)

**Workbuddy**

在简中环境里，不想给大家推荐其他的 AI Agent，即使我知道有更好的应用。但我想先把这个 AI 工具推荐给大家，因为它确实有很多的优势。

它不需要大家折腾网络、IP 等等乱七八糟需要技术有时候还有一点玄学的东西，Workbuddy 只需要你把它下载下来、登录一个邮箱，就可以正常使用了。

而且，目前它是可以免费使用 DeepSeek 4.1 flash 模型的，不用花钱买 Token，对于大部分人来说，很香，而且也够用。我的博客主题更换、性能优化等等，很多零碎的工作，都是借助 Workbuddy 以及它免费内置的 DeepSeek 4.1 flash 完成的。

但请一定下载国际版，不要下载国内版！

官网地址：https://www.workbuddy.ai/

**Codex**

我还保留在电脑上，但其实有了 Workbuddy 后，我已经很久没打开 Codex 了，Workbuddy 已经能够满足我日常的需求。

不推荐国内用户下载、折腾这个 Codex。

**Mimestream** 💰

我的 Gmail 客户端，省得我收邮件还需要每次打开 Gmail 网页。

这个 APP 还有一点好处：本来我想把 Gmail 添加到 Mac 自带的邮件软件里收发邮件，但是这要求网络一定是「直连代理」，规则模式下无效。但 Mimestream 就可以在规则模式下正常使用，我觉得很棒。

而且整个 APP 很轻量、手势交互很棒。

![Mimestream 使用](https://img.hulatu.com/post/vPpkYM.png)

软件官网：https://mimestream.com/ 

Homebrew 安装方式：`brew install --cask mimestream`  

## 辅助工具 {#fu-zhu-gong-ju}

**Raycast** 🆓

除了平常用来做 APP 启动器、文件搜索、窗口管理外。我还会使用它的 Snippet 功能，结合 AI 的一些「背景话术、固定话术、提示词」等等，来提高自己的效率。还有一些「网页信息」的填写，比如邮箱号、手机号等等。

在我的电脑上，我只需要输入 `!qmail`，就会自动出现我的 QQ email；输入 `!gmail`，就会出现我的 Gmail；输入 `!readpaper`，就会出现我调用 AI 阅读文献的提示词，这个功能我用得很高频。

Raycast 还有很多好用、实用的功能，我用得多的，就以上这些。

![Raycast 启动 APP](https://img.hulatu.com/post/3oO7Eh.png)

软件官网：https://www.raycast.com/ 

Homebrew 安装方式：`brew install --cask raycast`  

**Maccy** 🆓

粘贴板增强功能，我觉得很轻量、挺好用的。相比于 Raycast 自带的剪贴板，Maccy 完全免费，用着更安心、也没有保存条数和时间的限制。

![Maccy 粘贴板](https://img.hulatu.com/post/WcbsnG.png)

软件官网：https://maccy.app/ 

Homebrew 安装方式：`brew install --cask maccy` 

App Store 下载链接：[Maccy](https://apps.apple.com/us/app/maccy/id1527619437?mt=12)（App Store 版本付费；官网提供可免费下载的版本）。

**Keka** 🆓

一款无感的压缩、解压缩应用，好用够用。并且解压缩软件，也是电脑的必备软件。

软件官网：https://www.keka.io/en/ 

Homebrew 安装方式：`brew install --cask keka` 

App Store 下载链接：[Keka](https://apps.apple.com/us/app/keka/id470158793?mt=12)（App Store 版本付费；官网提供免费下载版本）。

**IINA** 🆓

一款精美、开源的万能播放器。我 Mac 上的音乐、经典的《武林外传》《请回答 1988》《疯狂的石头》等内容，都是用 IINA 这款播放器，够用。

虽然有时候播放我之前下载的 4K 高码率电影（《星际穿越》《沉默的羔羊》）会有一些轻微的掉帧卡顿，但毕竟用来看 4K 高码率的资源本来就少，所以这也不是个问题。

软件官网：https://iina.io/ 

Homebrew 安装方式：`brew install --cask iina`  

**Vista** 🆓

一款免费、简洁、果味十足的看图 APP，把我需要的「看图、找图」这件事做得挺不错。没有过多的花哨功能，设计也很简约大方。

App Store 下载链接：[Vista](https://apps.apple.com/us/app/vista-just-open-the-image/id6760483098?mt=12)

**MonitorControl** 🆓

如果你的 Mac 外接显示器，这个开源软件值得拥有，可以直接用 Mac 的亮度调节按键，调节外接显示器的亮度。

软件官网：https://monitorcontrol.app/ 

Homebrew 安装方式：`brew install --cask monitorcontrol`  

**DarkModeBuddy** 🆓

一款开源、简洁的自动切换明暗模式的小工具，可以自己调节在多少强度的光照下、持续多久，就切换为「黑暗/明亮模式」，弥补了 Mac（我的 macOS 15）上不能自动切换明暗模式的缺陷。

软件官网/项目主页：https://github.com/insidegui/DarkModeBuddy 

Homebrew 安装方式：`brew install --cask darkmodebuddy` 

**Transmission** 🆓

一款开源、简洁的磁力下载工具，有时候有些资源的下载，需要用到「磁力下载器」，实在不喜欢国产迅雷之流的 APP，这款软件简单清爽，用来以备不时之需。

软件官网：https://transmissionbt.com/ 

Homebrew 安装方式：`brew install --cask transmission`  

**Clash Verge Rev** 🆓

我的网络代理客户端，不多说，大家懂的都懂。PC 端，网络代理我首推这款软件。

软件官网/项目主页：https://clash-verge-rev.github.io/ 

Homebrew 安装方式：`brew install --cask clash-verge-rev`  

**ImageOptim** 🆓

一款开源、简约、小巧的图片压缩工具。我相信每个人都会有不少专属于自己回忆的照片，每当我们把它们备份保存在文件夹里时，有些图片的文件很大，这时候我们可以选中已经整理好的所有图片，用这个 APP 打开，它会自动压缩至合适的大小，并且清晰度几乎没有损失。

对于我这样有一些「数字洁癖」的人来说，挺有意义的。

软件官网：https://imageoptim.com/mac 

Homebrew 安装方式：`brew install --cask imageoptim`

**CotEditor** 🆓

CotEditor 很适合我这种非重度代码选手，有时候需要简单地修改一些代码的人使用。你甚至可以用它来作为 Markdown 写作软件，它很安静，语法支持也很好。

**VS Code** 🆓

如果你是个热爱使用电脑、喜欢钻研点电脑技术的人，VS Code 这个软件一定少不了，因为它就是电脑界、编程界的瑞士军刀。只要你有需求，可能它的一个插件就能解决。并且它的插件生态超级完备，基本上市面上所有你遇到过的、没遇到过的问题，都会有插件能够解决你的问题。

就算是非技术类人员，电脑里装一个 VS Code 有时候也能解决不少问题。

比如前段时间，我的博客图床从 GitHub 迁移到了 Cloudflare R2，图片链接需要从 `https://raw.githubusercontent.com/hulatu/img/refs/heads/main/uPic/XX.webp` 转变成 `https://img.hulatu.com/post/XX.webp`，显然 `https://img.hulatu.com` 这个更有我个人特点。当时我 GitHub 图床里的图片有 300 多张，如果我一张张改，很费时间。所以我打开 VS Code，用了一个文件夹搜索 + 批量修改功能，1 min 不到，300 多张图片的链接瞬间就改好了。

所以这是一个可以把复杂的活变得简单的工具，推荐大家用用、折腾折腾。

软件官网：https://code.visualstudio.com/ 

Homebrew 安装方式：`brew install --cask visual-studio-code`  

**iMovie 剪辑** 🆓

我用 Ice，主要是因为有时候微信这种软件需要长时间地挂载在后台，因为关闭后登录要用到手机，所以我就经常性地让微信停在后台。但是微信的菜单栏图标不能隐藏。以至于有时候微信有新消息，弹出数字 1、2、3……，我觉得对我的专注有不好的影响，于是我用 Ice 把微信等一些我不太需要显示在菜单栏的图标都隐藏了，感觉很好。

## Homebrew 安装命令汇总 {#homebrew-an-zhuang-ming-ling-hui}

以下命令适用于上文提到的、我已确认有对应 Homebrew 包的 App。Capso 需要先添加项目自己的 tap；系统自带的软件如 Safari、备忘录和提醒事项不需要安装。

```bash
brew install --cask wechat
brew install --cask microsoft-office
brew install --cask typora
brew install --cask netnewswire
brew install --cask helium-browser

```

Homebrew 安装前，也可以用 `brew info --cask 软件包名` 查看包信息。软件包名与 App 显示名称不一定相同；安装前建议核对 [Homebrew Cask 官方目录](https://formulae.brew.sh/cask/)。
