# 胡拉图的周刊-第二十期

这次周刊，是我做个人周刊以来的第 **20** 期。

虽然周刊这个板块，数据一直不太好，相比于我那些有流量的文章来说。但对少部分人而言、对我自己而言，以周刊这种形式去做一些内容，收获还是大不一样的。

![读者留言](https://img.hulatu.com/post/IOVVSd.png)

比如，我个人平日里的短文 or 长文，其实参考别人的内容比较少，基本都是基于自己的一些日常体验、感受和思考，去书写的「真实感」比较强的内容。

而周刊，更多的是比较权威、比较科学的一些网站、平台的内容的二次解构、思考和分享。这里面有很多东西的「权威性、科学性」肯定是我个人所比拟不了的，我也需要一直学习。

趁着我自己学习的过程，顺带着把它们记录、分享出来，或许，会给一些人带去帮助，这就是我这个栏目的最大意义了。

当然，如果你们喜欢我的周刊栏目。还请多多点赞、推荐、评论、转发、关注我，这对我真的帮助很大，可以支撑我有更大的热情做出更优质的内容。

## 博客新加跑步数据

![跑步数据](https://img.hulatu.com/post/CJuUas.png)

新学年开始了，大一、研一新生在这段时间内一批批涌进来，我貌似已经成了这个学校的「老人」——环境都了解了、什么都见识了、小道消息也知道一点。

如此，越是看到这些新生的青涩、稚嫩、对新环境的一切都感到新奇；我就越发觉得自己好像有点大了、成熟了。

但冥冥中，我在内心也涌动着一股能量吧——我也想在新学年给自己一个好气象、让自己的研究生生涯，有个完美的终章。

没错，我又要开始大量的跑步了。

上一次我很规律、大量的跑步，还是在刚拿到 Garmin 255 手表时 [关于佳明255，我的体验分享](https://mp.weixin.qq.com/s/e331U7drWoQVCfmIYCkKuA)、 [运动手表被顺走，慢慢从数据依赖回归身体感知](https://mp.weixin.qq.com/s/BOMEj8qYLCb2NAN53gxQ0g) ，非常的激动和新奇，想着让自己奔向更加专业的方向去变成一个跑步健将。

但跑够 500 km 后，我的热情变平淡了，而且更多的对力量训练感兴趣并且投入大量精力。

一段时间过后，我的身体也确实变宽了、Size 也膨胀了好几个维度，我师姐亲口对我说我好想「充气了」。暑假回到家时，家里人和大姨也都说我好像比过去「胖了」……

好像很多人，对于身材的理解，还只停留在「非胖即瘦」的维度。

我之所以给自己的博客添加跑步数据统计、链接我的 Garmin 手表数据，最重要的原因其实是内在的。

我喜欢跑步，试过骑行、试过力量训练、试过打球等等，跑步真的是我觉得最纯粹、最随性、最自由的运动模式。

也希望跑步可以重新给我一个好的开始、一个好的结局。

## 从 0 做自媒体的方法

**出处**：[2026年从0到1成为全职博主（辞掉工作）的具体方法｜35分钟超详细干货](https://www.youtube.com/watch?v=JXdcUqwH2mM)

**主要内容**：

**设备**

- 正在用的手机
- 能用的三脚架
- 平价的麦克风

**平台**

先做好一个平台

- 自己平时喜欢看的平台
- 有网感懂他们的文化，更容易做出符合社区文化的作品
- 要学习的东西很多，不要被多平台挤占自己学习运营相关技能的时间

**内容方向**

- 自己的兴趣爱好， 有一定的经验或者技能
- 用户存在持续而明确的需求
- 自己是否愿意长期做这个
- 这些用户愿意为更好的解决方案付费

- 如果暂时不知道自己擅长什么，可以回顾三个方面：
  - 别人经常向你请教什么？
  - 你曾经成功解决过什么问题？
  - 你在哪些事情上比普通人更有经验？

**自我**

- 用好 AI （ChatGpt）了解自己、给自己规划一个方向
- 找好对标账号，参考风格，找选题
- 用一个小号刷内容，多输入
- 学习「低粉爆款」视频——培养自己的敏感度

**开始**

- 第一期视频——模仿
- 做出一个完整的产品

**频率**

- 最好一周一个视频，便于视频平台识别自己
- 规律自己创作内容的节奏

**总结分析**

- 为什么数据好、内容、表达、选题
- 针对观众，了解受众群体

**优化流程**

- 减少阻力
- 提高完成的效率

**调节自己**

- 接受、面对孤独感
- 成为全面、立体的人

**产品**

不是要等到做大，才可以开始变现。

最小化产品，就是能够解决一个具体问题，又不需要投入大量成本的产品或服务，例如：

- 一次一对一咨询
- 一份模板或者资料包
- 简历修改、设计或者剪辑服务
- 一节小型线上课程
- 一个七天或十四天的陪跑计划
- 一本解决具体问题的电子书

**思考**：

以上是我看到过的非常优质的一个新人小白从 0 开始做自媒体的经验分享。大都是很实用、受用的分享，谢谢大米姐姐。

但我觉得大米姐姐，以及其他分享自媒体经验的创作者，大都容易忽略他们自带的一些特点，或许这也是他们成功的原因。

- 有着非常不错的颜值、气质
- 有着让人舒服表情控制、皮肤状态
- 有着与自媒体相关的工作基础经验

以上这些创作者所没有关注到的「个人优势」，其实在如今这个时代，也是稀缺资源，会或多或少影响一个账号的走向。

但如果是对于「小白」来说的话，这个视频里分享的内容，已经足够有价值了。
