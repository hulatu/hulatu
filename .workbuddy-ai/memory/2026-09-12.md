### 现状（用构建产物反推，Bash 仍不可用）

| OG 分享图 | ❌ 没生成 | `public/og/` 目录压根不存在 |

**构建时间**：`public/index.xml` 的 `lastBuildDate` = `Sat, 12 Sep 2026 19:24:22 +0800`；
`data/hot.json` 的 `generated` = `19:23:56`。**构建比数据晚 26 秒 → 用的就是新数据**，
所以「评论数是 0」不是构建过期，是真 bug。这一步排除了最省事的解释，很关键。

### 真凶：Hugo `strings.Trim` 的参数顺序

```gotemplate
{{- $key := $page.RelPermalink | lower | strings.Trim "/" -}}   ← 错的
```

Hugo 官方文档：**`strings.Trim STRING CUTSET`**（字符串在前、cutset 在后），
和 `TrimPrefix` / `TrimSuffix` 的顺序**相反**。管道会把值塞进**最后一个**参数位，
于是上式实际等于 `strings.Trim("/", <路径>)`：被修剪的字符串是 `"/"`，cutset 是整条路径，
`/` 的字符全在 cutset 里 → **结果恒为空串**。

每页 key 都是 `""` → `index $stats ""` 恒为 nil → 所有 `comments`/`views` 输出 0，
`post-stats.html` 因两个数都是 0 而整块不输出。**全程不报错、不中断构建**，所以上一次会话
「人工审读语法」没发现。已改：

```gotemplate
{{- $key := strings.Trim (lower .RelPermalink) "/" -}}          ← 对的
```

**改动**：`layouts/partials/post-stats.html:11`、`layouts/index.postindex.json:10`
（两处都加了注释说明这个坑）；顺带修正 `scripts/fetch_hot.py` docstring 里引用的错误表达式、
`MAINTENANCE.md:229` 的同样错误（并加了 ⚠️ 警告块）、`scripts/og-images.py` 过时的 docstring
（还写着「在 deploy.sh 中调用」）。

## 重大架构纠正：部署其实完全靠 Cloudflare Pages 的 Git 集成

用户告知两件事：① Cloudflare Pages **确实**关联了这个 GitHub 仓库；② `wrangler whoami` → command not found。

**这推翻了上一节的 OG 修复。** 重新梳理真实链路：

```
up → publish.sh（刷热门榜 → 生成 OG → commit → push → 同步 Garmin → pull → push）
   → hugo --minify         ← 只写本地 public/，而 public/ 在 .gitignore 里
   → og-images.py public   ← 同样写进 public/，永远上不去
   → wrangler pages deploy ← command -v wrangler 不通过，整个分支被跳过

真正的部署：Cloudflare Pages 监听到 push → 平台自己跑 hugo → 发布
```

结论：**任何只写进本地 `public/` 的产物都永远上不了线**。想在线上出现只有两条路——
提交进 git（由平台构建产出），或放进 `static/`（Hugo 构建时原样复制）。
`data/hot.json` 走的是前者，所以热门榜和评论数/阅读数在线；`public/og/` 两者都不是，所以一直 404。

另外确认：**Cloudflare Pages 构建镜像里没有 ImageMagick**（官方 build-image 文档的工具表只有
Bundler / Dart Sass / gem / Hugo / npm / pip / pipx / pnpm / Poetry / Yarn / Zola），
而本机脚本又硬编码了 macOS 字体 `/System/Library/Fonts/Hiragino Sans GB.ttc`
→ 「让平台构建时生成 OG 图」这条路不可行。

### 用户选了「提交到 static/og」

- `scripts/og-images.py`：输出固定为 `ROOT/static/og`；不再接受参数（传参会警告并忽略）；
  加「字体不存在就跳过」守卫；logo 临时文件改用 `tempfile.mkdtemp()`（原来写在输出目录里，
  万一中途崩溃会把 `.logo-64.png` 留在 `static/og` 里被一起提交）

  会把没进 `$STAGE` 的 `og/` 一起删掉）
- `up`：删掉 2.5 步和 wrangler 上传分支，第 3 步改成说明「部署交给平台」
